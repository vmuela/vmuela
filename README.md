# Hola, soy Valente Muela

Desarrollo software con .NET y Flutter. Trabajo en MasterTrack GPS, una plataforma
de rastreo y telemetría para flotillas, y creo mis propias aplicaciones web.

## Proyectos

| Proyecto | Qué hace | Stack |
|---|---|---|
| VizitIA | Registro de visitas y entregas a clientes para negocios pequeños | Blazor WASM, Supabase |
| Running Analysis | Análisis de archivos GPX con mapa y estadísticas | Blazor WASM, Leaflet |
| Expense IA | Registro de gastos diarios por categoría | Blazor WASM, Supabase |

## Con qué trabajo

- **Web:** C#, .NET 10, Blazor WebAssembly, Radzen, Bootstrap
- **Móvil:** Flutter
- **Datos y backend:** SQL Server, Supabase (PostgreSQL), ASP.NET
- **Dominio:** protocolos GPS y telemetría (Teltonika, Suntech, Queclink, Ruptela)
