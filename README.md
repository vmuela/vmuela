# Hola, soy Valente Muela

Desarrollo software con .NET y Flutter. Trabajo en MasterTrack GPS, una plataforma
de rastreo y telemetría para flotillas, y creo mis propias aplicaciones web y móviles.

## Proyectos

| Proyecto | Qué hace | Stack |

| **VizitIA** · [app](https://vizitia-app.pages.dev/) · [sitio](https://vizitia.pages.dev/) | Programa y da seguimiento a visitas y entregas a clientes: panel web y app móvil para registrar llegada y salida | Blazor WASM, Flutter, Supabase |
